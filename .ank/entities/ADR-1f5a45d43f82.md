## Context

`ank init` writes a pointer paragraph into `AGENTS.md` through `ensure_line`
(crates/ank-cli/src/init.rs), which appends it whenever that exact line is
absent. `init` is also the repair command: `status` and `check` name it for a
missing refspec. So a repository whose maintainers removed the pointer on
purpose gets it back on every repair.

Observed on 2026-10-11 in this repository: `AGENTS.md` reads `See CLAUDE.md —
same conventions for every agent.`, and `ank init`, run to add the refspec,
appended `This repo uses Ank: tasks and decisions live in .ank/.` and reported
`pointer added to AGENTS.md`.

## Decision

`init` writes the `AGENTS.md` pointer only on the run that creates `.ank/`. A
run on a repository that already has `.ank/` repairs the plumbing it owns
(refspec, `.gitattributes`, `.gitignore`, `config.yml` when absent) and leaves
`AGENTS.md` as it finds it, created or not.

## Consequences

The pointer is a bootstrap aid, not an invariant. A team that deletes it keeps
it deleted; a team that wants it back writes it.
